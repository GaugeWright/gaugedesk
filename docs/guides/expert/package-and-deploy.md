# Package an agent for another team

A package contains one fixed agent version for another team to inspect and
accept. It grants no access to the recipient's files.

1. Select a tested, fixed version and choose **Package**.
2. Add its tools, provider policy, protection settings, and only the required
   initial files. Never include credentials.
3. Review and create the package.
4. Send it through the approved route.
5. The recipient verifies the owner, identity, version, tools, provider, files,
   and limits before accepting or refusing it.
6. After acceptance, the recipient adds it to a project and grants exact access
   for each run.

Payment, delivery, or possession does not grant permission to run or read
files.

For a website, see [Publish on a website](../embed/index.md). Managed private or
attested deployment requires GaugeWright support; check
[Product status](../../reference/status.md) before committing to it.
