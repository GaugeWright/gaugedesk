# Work with another team

GaugeDesk can transfer a fixed agent or reviewed result between teams. Each
team keeps control of its own files and approvals.

## Receive an agent

1. Identify the sender and fixed agent version.
2. Review the provider, tools, files, and limits.
3. Test denied access.
4. Accept or refuse the package.
5. If accepted, add it to a project.
6. Allow only the files needed for each run.

Use [Check an agent before you use it](verify-before-trust.md).

## Receive a result

1. Confirm the source, version, and intended recipient.
2. Review the actual content.
3. Check required approvals.
4. Accept or refuse the result.

Use [Review work from an agent](review-and-release.md).

## Important limits

- The model provider receives prompts and allowed files in plaintext.
- General managed cross-team service availability is not established.
- Managed and independently verified hosting are not generally available.
- GaugeWright does not have SOC 2 or ISO 27001 certification or a completed
  independent penetration test.

See [Product status](../../reference/status.md) before you make a customer
commitment.
