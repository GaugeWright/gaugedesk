# Review work from an agent

Agent work remains a candidate until a person accepts it.

## Keep or discard local work

1. Open **Changes** and compare each file with its starting version.
2. Check the task requirements, unwanted edits, private data, credentials, and
   destructive actions.
3. Run the required tests.
4. Select **Keep** or **Discard**.

Keeping a result does not send it outside the project.

## Release work

Before releasing content to another person, team, or system, confirm the exact
files and version, recipient, purpose, target, required approvers, and whether
the action is reversible. A content change requires a new review.

Do not copy content around a hold or release gate with another tool.

Downloaded website results enter quarantine. Verify their deployment, release
version, schema, size, and content before admitting them to a project.
