# People and access

This guide explains the derived View for `access.json`. The JSON document remains the inspectable source for this surface.

Review active members, fixed roles, project grants, and sessions. Role and grant changes are governed separately; billing status never grants access.

## Using the agent

Ask the Admin agent to explain this file or prepare a reviewed patch. The agent cannot use a shell or the web, cannot reveal credentials, and cannot admit its own proposal.
