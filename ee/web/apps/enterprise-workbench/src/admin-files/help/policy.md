# Policy

This guide explains the derived View for `policy.json`. The JSON document remains the inspectable source for this surface.

Security, placement, and archetype-approval policies may only narrow the verified floor. Requiring MFA records organization policy; the configured identity provider performs the factor challenge.

## Using the agent

Ask the Admin agent to explain this file or prepare a reviewed patch. The agent cannot use a shell or the web, cannot reveal credentials, and cannot admit its own proposal.
