# Identity

This guide explains the derived View for `identity.json`. The JSON document remains the inspectable source for this surface.

Configure OIDC or SAML and provisioning. Test evidence is operational until admitted. SCIM credentials are shown once by the manual control and never become file or agent content.

## Using the agent

Ask the Admin agent to explain this file or prepare a reviewed patch. The agent cannot use a shell or the web, cannot reveal credentials, and cannot admit its own proposal.
