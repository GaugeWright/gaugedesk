# Organization

This guide explains the derived View for `organization.json`. The JSON document remains the inspectable source for this surface.

Configure the organization display name, verified domains, and default residency region. Domain verification is an admission fact; typing a domain does not prove control of it in a hosted deployment.

## Using the agent

Ask the Admin agent to explain this file or prepare a reviewed patch. The agent cannot use a shell or the web, cannot reveal credentials, and cannot admit its own proposal.
