# Machines

This guide explains the derived view for `machines.json`. The JSON document
remains the inspectable source for this surface.

Self-managed and GaugeWright-managed machines appear in one list. Internally,
only a matching, live, target-admitted Home projection contributes project and
placement inventory. Stale, partial, redacted, unreachable, and
identity-mismatched sources remain unknown.

## Using the agent

Ask the Administration agent to explain this document or prepare a reviewed
patch. The agent cannot use a shell or the web, cannot reveal credentials, and
cannot admit its own proposal.
