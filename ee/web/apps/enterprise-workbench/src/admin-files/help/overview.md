# Overview

This guide explains the derived View for `overview.json`. The JSON document remains the inspectable source for this surface.

The overview joins already-admitted projections for orientation. It is not a stored compliance score. Counts exclude every Home whose projection is not live.

## Using the agent

Ask the Admin agent to explain this file or prepare a reviewed patch. The agent cannot use a shell or the web, cannot reveal credentials, and cannot admit its own proposal.
