# Client sessions

This guide explains the derived View for `clients.json`. The JSON document remains the inspectable source for this surface.

Reported version, protocol, channel, and platform are compatibility evidence. They do not attest the device or binary and this projection is read-only.

## Using the agent

Ask the Admin agent to explain this file or prepare a reviewed patch. The agent cannot use a shell or the web, cannot reveal credentials, and cannot admit its own proposal.
